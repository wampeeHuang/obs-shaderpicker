  OBS 着色器选型器 · 汉化包 + 可视化包 使用说明
════════════════════════════════════════════════════════════════

一句话：这是一个一键安装包。双击 install.bat，自动把"汉化插件 + 选型器面板"装进你的 OBS，并在 OBS 里加一个停靠窗口，可以点缩略图切换 142 种着色器效果。


────────────────────────────────────────────────────────────────
一、这算不算"软件安装包"？
────────────────────────────────────────────────────────────────

算，但不是传统意义上的 MSI/EXE 安装程序。准确说是一个"绿色一键安装包（脚本安装包）"：

    安装方式            双击 install.bat，自动完成全部安装
    与传统安装程序的区别  没有数字签名；Windows 可能弹 SmartScreen/未知发布者提示；没有自带的卸载程序
    优点                绿色、无后台服务、无 Node、无端口占用、装完即可用

如果你把它当"双击就装好的东西"来用，体验和传统安装程序一致。安装时弹出的提示是正常现象，不是病毒。

三、安装前提条件（重点）
────────────────────────────────────────────────────────────────

装之前先对照下表，你属于哪一类，就按哪一列的应对方式处理。

A. 完全没装 OBS
   安装包会怎么做：检测不到 OBS，提示"请先安装 OBS Studio"并中止。
   你需要做什么：先到官网 https://obsproject.com 免费安装 OBS Studio，装完再运行本安装包。

B. 有 OBS、从没装过这个插件（最常见）
   安装包会怎么做：自动定位 OBS 目录，全新安装。
   你需要做什么：什么都不用做，双击就行。

C. 有 OBS、已经装过 obs-shaderfilter 插件
   安装包会怎么做：检测到已装过，提示"将覆盖为汉化版"。
   你需要做什么：放心覆盖。你已应用的效果保存在 OBS 场景文件里，不会丢。

D. OBS 版本太旧（28 版以前）
   安装包会怎么做：检测到缺少 WebSocket 组件，警告提示升级。
   你需要做什么：建议先升级 OBS 到最新版再装（否则面板连不上）。

E. OBS 正在运行
   安装包会怎么做：提示检测到 OBS 正在运行，5 秒后若没关会自动帮你关掉再装。
   你需要做什么：什么都不用做，脚本会自动处理。

F. 没有管理员权限
   安装包会怎么做：自动弹 UAC 提权窗口。
   你需要做什么：点"是"。

G. OBS 装在非默认目录
   安装包会怎么做：自动检测常见位置 + 注册表；都找不到时让你手动输入路径。
   你需要做什么：按提示输入 OBS 安装目录，例如 C:\Program Files\obs-studio

需要满足的唯一硬前提是 A 之外：必须已经装了 OBS（28 版及以上最好）。其余情况脚本都有对应处理。


────────────────────────────────────────────────────────────────
四、安装步骤
────────────────────────────────────────────────────────────────

1. 下载并解压本包（得到一个文件夹）。
2. 双击文件夹里的 install.bat。
3. 若弹出 Windows 提示（SmartScreen/"是否运行"），点"更多信息 → 仍要运行"。
4. 弹 UAC 提权窗口时点"是"。
5. 等脚本自动完成（约几秒），提示"安装完成"。
6. 安装完成后，自己打开 OBS 开始使用。


────────────────────────────────────────────────────────────────
五、第一次使用（30 秒上手）
────────────────────────────────────────────────────────────────

1. OBS 顶部菜单：停靠窗口 (Docks) → 勾选"OBS 着色器选型器"。
2. 面板出现在 OBS 里，显示效果缩略图。
3. 面板默认操作你 OBS 里名为"摄像头"的采集源。如果你的采集源不叫这个名字：
   - 点击面板右上角的"设置"按钮，把"源名称"改成你的采集源名称，保存。
4. 点任意缩略图 → 该着色器效果立即应用到你的源上（实时预览）。

面板通过 OBS 自带的 WebSocket 服务连接（本地端口 4455），密码已自动配置好，无需手动设置。


────────────────────────────────────────────────────────────────
六、升级 / 重装 / 卸载
────────────────────────────────────────────────────────────────

升级/重装：重新运行 install.bat 即可。密码和停靠窗口位置会自动保留，不重复生成。

卸载（手动）：
1. 删除 OBS 插件文件：<OBS安装目录>\obs-plugins\64bit\obs-shaderfilter.dll
2. 删除插件数据：<OBS安装目录>\data\obs-plugins\obs-shaderfilter\
3. 删除面板：<OBS安装目录>\data\obs-shaderpicker\
4. 在 OBS 里移除停靠窗口：菜单 停靠窗口 → 移除"OBS 着色器选型器"


────────────────────────────────────────────────────────────────
七、常见问题
────────────────────────────────────────────────────────────────

问：双击 install.bat 后一闪而过？
答：权限/脚本问题。右键 → 以管理员身份运行。

问：提示"未找到 OBS"？
答：OBS 没装，或装在很偏的位置。先装 OBS，或手动输入目录。

问：提示缺少 obs-websocket.dll？
答：OBS 版本太旧。升级 OBS 到 28 版以上。

问：面板打开但连不上 / 不生效？
答：OBS WebSocket 没启用，或端口被占用。工具 → WebSocket 服务器设置 → 勾选"启用"，端口 4455。

问：面板没有反应，但"摄像头"源不叫这名？
答：默认源名称不匹配。面板"设置"里改成你的采集源名称。

问：想恢复英文原版？
答：覆盖安装后想要原版，手动卸载本包（见第六节），再从上游重装原插件。
